BUILD THE JAR
Option A (PC): install Java 25 + Gradle 9.4, run "gradle build" here. Jar: build/libs/donut-auction-1.0.0.jar (not the -sources jar).
Option B (no install): make a free GitHub repo, upload this folder's contents, open Actions > "Build jar" > Run workflow, then download the "donut-auction-jar" artifact.
INSTALL: put the jar in .minecraft/mods with Fabric Loader 0.18.4+ and Fabric API 0.152.1+26.1.2.
